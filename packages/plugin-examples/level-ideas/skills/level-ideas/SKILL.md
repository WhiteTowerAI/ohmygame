# Level ideas

1. Read the project's design notes and its existing levels first, so ideas fit
   the game's mechanics, controls and art.
2. Offer three to five levels. For each, give a name, the one new idea it
   teaches or tests, a rough layout from start to goal, and where it gets hard.
3. Keep each idea buildable with what the game already has; name any new asset
   or mechanic it needs.
4. Ask which to build before changing any files.
